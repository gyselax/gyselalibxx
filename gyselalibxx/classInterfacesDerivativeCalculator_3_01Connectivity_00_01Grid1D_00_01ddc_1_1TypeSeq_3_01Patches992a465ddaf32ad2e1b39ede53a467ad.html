Detailed Description

This operator is implemented for conforming equivalent global meshes.

When we call the operator .solve_deriv() or .solve_cross_deriv(), the operator loops over the interface to compute the vector C_trunc to determine all the interface derivatives and update the DerivField given in input.

The vector C_trunc is given by the coefficients (see README), [{\sum_{k = - N_{reduc}}^{N_{reduc}} \omega_{k, N_{reduc}, N_{reduc}}^{i_I} f_{i_I+k} }_I]

with * \(N_{reduc}\) the number of chosen cells for the approximation, * \(i_I\) the index of the grid at the Ith interface, * \(f_{i_I+k}\) the function values if we compute the first derivatives, or the first derivatives if we compute the cross-derivatives.

Template parameters:

  • Connectivity A MultipatchConnectivity class describing all the patch connections.
  • Grid1D A given direction.
  • Patches List of patches containing all the involved patches in the given direction.
  • DerivCoeffCollection A InterfaceDerivCoeffsCollection that stores the InterfaceDerivCoeffs needed to compute the interface derivatives.
