# Gyselalib++ Installation

actions:
* installer Spack
* activer Spack
* installer un nouvel environnement

## gys-spack

* install Spack:
  * location, optional default for each platform, fails if already present
  * group, optional default for each platform
* activate Spack:
  * location, optional default for each platform, fails if not present
